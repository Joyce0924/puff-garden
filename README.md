# 蓬蓬小岛

Vite + 原生 JavaScript + Matter.js + Canvas，无重力的移动端物理动画原型。

## 运行

在此目录打开终端：

```sh
npm install
npm run dev
```

电脑访问终端打印的 Local 地址（通常 http://localhost:5173）。手机与电脑连接同一 Wi-Fi，在手机浏览器打开终端打印的 Network 地址（例如 http://192.168.1.10:5173）。不要在手机上输入 localhost；如无法连接，检查电脑防火墙、访客网络隔离与 VPN。

```sh
npm run build
npm run preview
```

## 参考运动分析与实现

根据用户录屏 3–7 秒关键帧观察：3–4 秒物品由中心局部簇向外扩容；近邻先移动，再传至外圈，各物品朝向有差异。4.5–6.5 秒夹杂圆环、消除和替换，不能把全部位移归因于生成。这里只提取中心生成、局部挤压传递、受限聚集与快速衰减的规律，不复制素材或加入消除玩法。视频不能证明原作采用的引擎、碰撞形状或具体参数，下列数值是本原型的调校值。

- 每批最多 6 个，默认间隔 280ms；在中心半径 36px 内搜索无重叠的种子位置。空间不足时物理施力清出局部空隙，超时停止。
- 新生刚体从半径 4px 逐步长大，默认约 0.48 秒到目标大小；允许前后物品生长阶段交叠，实现连续冒出。
- 独立 40 边近圆刚体与真实接触解算传递挤压力；不设置物品位置来模拟碰撞。生长单调，视觉使用衰减振荡缩放，避免碰撞体反复缩放引起抖动。
- 柔和中心引力、空气阻尼与旋转阻尼让物品保持成团，外圈超过 138px 时加强回收，屏幕边界静态墙兜底。
- 固定 120Hz 物理小步长，16 次位置迭代、12 次速度迭代。动画速度只改变累计模拟时间，不放大单步时间。
- 按中心圆形区域容量限制生成，最多 44 个，默认半径下 31 个；外观半径为碰撞半径约 94%，保留识别间隙。

## 参数

展开页面的“调一调小岛”：

| 参数 | 默认 | 效果 |
| --- | --- | --- |
| 碰撞半径 | 19px | 越大越拥挤，修改会重置场景 |
| 碰撞弹性 | 0.45 | 越大碰撞后回弹越明显 |
| 聚拢力度 | 0.65 | 越大越快回收、整体越紧凑 |
| 生成间隔 | 280ms | 越小越连续；中心没有空隙时自动延迟 |
| 动画速度 | 1× | 调整物理与生长的整体时间速度 |

建议先用默认参数体验；想更密集，可用 220ms / 聚拢 0.8；想观察碰撞传递，可将动画速度降到 0.5×。

## 限制

保留 Vite + JavaScript + Matter.js + Canvas，小规模原型无需额外 PixiJS 或 GSAP。没有倒计时、分数、音效或完整玩法。Matter.js 为离散求解，接触允许亚像素级压入，不承诺数学上的零重叠。仅使用原创程序绘制的小居民，圆形轮廓不等同于参考里的不规则物体。手机实际帧率与视觉手感仍需实机确认。
