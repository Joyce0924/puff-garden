# 蓬蓬小岛

Vite + 原生 JavaScript + Matter.js + Canvas，无重力的移动端物理动画原型。

## 运行

在此目录打开终端：

```sh
npm install
npm run dev
```

电脑访问终端打印的 Local 地址（通常 http://localhost:5173）。手机与电脑连接同一 Wi-Fi，在手机浏览器打开终端打印的 Network 地址（例如 http://192.168.1.10:5173）。不要在手机上输入 localhost；如无法连接，检查电脑防火墙、访客网络隔离与 VPN。

```sh
npm run build
npm run preview
```

## 机制与限制

- 初始 10 个圆形刚体均匀排列于中心环形区域，颜色不同。
- 默认每次随机生成 2–4 个，可设置固定数量。
- 通过 Matter.js 的 applyForce 将中心附近刚体推开，有空隙才加入半径 5 的新刚体，按物理步逐渐长大。一次仅生长一个；忙碌期间禁用生成按钮。
- 固定 120 Hz 物理步长，12 次位置迭代、10 次速度迭代；速度限制控制在稳定范围。渲染使用 requestAnimationFrame 和最高 2 倍像素密度。
- 采用四面静态墙与保守的 46% 面积容量限制。中心腾空超时会取消剩余生成；全局尚有空间也可能因局部拥挤而取消。
- 尺寸变化重置，弹性与空气摩擦即时应用。摩擦滑块控制漂浮的空气阻尼；接触摩擦固定为 0.08。
- Matter.js 属于离散碰撞解算器，不保证数学上的零重叠。生长及接触时可能有短暂微小压入；这里通过慢速生长、小时间步、容量与速度限制降低风险。所有运动由刚体力、速度与碰撞求解产生，没有位置补间动画。
- 当前为竖屏原型，没有分数、计时、声音或完整游戏规则。Canvas 绘制的脸部装饰不额外参与碰撞。
