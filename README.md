# 蓬蓬小岛：配对 MVP

在线试玩：https://joyce0924.github.io/puff-garden/

## 运行

```sh
npm install
npm run dev
npm test
npm run build
```

电脑打开终端 Local 地址。手机与电脑连接相同 Wi-Fi 后打开 Network 地址；在线版本无需电脑开机。

## 玩法

点击开始游戏，初始 10 个物品，每轮恰好一对相同图案。点击其中任意一个即可 +100 分，两枚一起消失，继续生成下一轮。每轮可操作时间 10 秒，正确后重置时间；点错扣心，三颗心耗尽或超时结束。生成过渡期间暂停计时和点击。

每轮移除 2 个、补入 4 个，净增 2 个；到达容量或镜头下限后只补回缺少数量。每轮重新洗牌分配图案，相同图案底色也相同。56 个不同符号组成素材池，可继续扩展，超出时使用编号符号。

## 职责分离

- `game.js`：游戏阶段、分数、生命、计时及唯一重复对。
- `camera.js`：碰撞边界包围盒、平滑镜头、逆坐标变换。
- `src.js`：保留第一阶段 Matter.js 物理和中心生成机制，连接渲染与输入。

镜头仅改变渲染，不改变现有刚体坐标、尺寸或速度。使用中心对称包围盒，横向 24px、纵向 50px 安全边距；0.5 秒 smoothstep 缓动，缩放范围 0.9–1.8，变化阈值 0.025。单局只拉远，重开才复位，避免碰撞和消除引发反复推拉。点击坐标先从 CSS 尺寸映射到 Canvas 逻辑尺寸，再做镜头逆变换，使用 Matter.Query.point 检测。

## 保留的物理机制

无重力，中心半径 36px 内寻找空隙，种子刚体从半径 4px 缓慢扩大。中心吸引与空气阻尼维持物品聚集。固定 120Hz、40 边近圆碰撞体、速度限制及静态边界。默认容量 31 个，按半径调整，上限 44 个。仍可能出现短暂亚像素接触压入，不保证数学上的零重叠。

参考录屏 3–7 秒：提取中心局部扩容、近邻到外圈的传递、旋转和减速聚拢；没有复制参考素材或加入其中的复杂消除特效。

## 调参

开始前或结束后展开“调一调小岛”；游戏中锁定参数以保持公平。

| 参数 | 默认 | 效果 |
| --- | --- | --- |
| 碰撞半径 | 19px | 改变占位与容量，修改重置 |
| 弹性 | 0.45 | 越大碰撞回弹越明显 |
| 聚拢力度 | 0.65 | 越大收拢越快 |
| 生成间隔 | 280ms | 越小生成越连续，拥挤时自动延迟 |
| 动画速度 | 1× | 改变物理时间速度，不改变实际倒计时 |

## 验证范围

npm test 覆盖 5100 次唯一配对分配、分数、生命、超时、重开、镜头缓动/阈值/下限及坐标逆变换。无界面集成测试模拟 18 轮连续游戏、真实刚体命中和容量限制。构建通过。浏览器权限限制下尚未完成手机实际触摸和视觉验收。
